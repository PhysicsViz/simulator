# Physics Simulator

Interactive physics simulations for teaching, built as a static site with plain HTML, CSS, and JavaScript — no framework, no build step, no external dependency.

Developed as the practical part of a master's thesis on physics teaching, targeting **first-year civil-engineering students (Physics 1, BAC1)**. Each exercise renders a physical phenomenon on an animated canvas with a free-body diagram showing every applied force, full time control (play/pause, speed, scrubbing), editable parameters, and formulas displayed with their current numeric values substituted. UI is in French with an English toggle.

## Live Site

Deployed via GitHub Pages. Open `index.html` for the exercise list.

## Exercises

### Mechanics

| Exercise | Description | Concepts |
|---|---|---|
| [Projectile motion](src/mechanics/projectile-motion/index.html) (Tir parabolique) | A point mass launched from height h₀ with speed ‖v⃗₀‖ at angle θ (−90° to 90°), under uniform gravity (fixed mass m = 1 kg), air resistance neglected. Animated trajectory with free-body diagram, weight/velocity/acceleration vectors, camera zoom/pan, time scrubbing, playback speed and time graphs (positions, velocities, accelerations); adjustable ‖v⃗₀‖, θ, h₀, g. Formulas follow the course formulary notation (u₀/v₀ components, MRU/MRUA). Includes an experimental game mode: shoot a basketball into a hoop of random distance, height and rim size — formulas and predicted path hidden, parameter changes reset the shot, progress through milestone tiers (1–100 baskets) with a stats panel. | Kinematics, parabolic trajectory, flight time, range, maximum height, weight P = m·g |
| [Pendulum](src/mechanics/pendulum/index.html) (Pendule) | A point mass on a rigid massless rod, no friction, integrated with RK4 (no small-angle approximation); adjustable release position θ₀, initial tangential speed v₀, rope length L, mass m and g. Scene shows the rod, swing arc, weight/tension/velocity/acceleration vectors and a free-body diagram; formulas in course circular-motion notation (v = L·ω, a_r = −L·ω², a_θ = L·α), energy conservation and small-angle period; time graphs of θ, v and accelerations. Experimental game mode "Casse-mur": smash the orange wall WITHOUT breaking the gray wall behind it — thresholds and the rope tension limit are drawn on the scene, the rope snaps above T_max, and the start position is forced away from the walls. | Circular motion, equation of motion α = −(g/L)·sin θ, energy conservation, tension, period |

| [Uniform circular motion](src/mechanics/uniform-circular-motion/index.html) (Mouvement circulaire uniforme) | An object at constant speed v on a circle of radius R (adjustable R, v, m): θ(t) = ω·t, ω = v/R, period, purely centripetal acceleration a_r = v²/R and net force ΣF = m·v²/R, with sinusoidal time graphs of the x/y components. Experimental game mode "Ne mouille pas le prof !": the classic bucket-of-water-in-a-vertical-circle problem — too slow at the top (v < √(g·R)) and the water falls on the teacher, too fast and the rope snaps at the bottom (T > T_max); challenges are guaranteed to have a winning speed window. | Uniform circular motion, ω = v/R, centripetal acceleration, period, vertical-circle tension |

| [Inclined plane](src/mechanics/inclined-plane/index.html) (Plan incliné) | A block launched parallel to a slope (adjustable α 0–90°, m, v₀, single friction coefficient μ = μ_s = μ_k): N = m·g·cos α, f = μ·N opposing the motion, piecewise MRUA (up, stop, slide back if tan α > μ, blocked at the bottom corner), static equilibrium check, stopping distance formula; time graphs of s, v, a. Experimental game mode "Défi pente": the slope is imposed and the student tunes v₀ and μ to either bring the block to a permanent stop inside a zone (which also requires μ ≥ tan α) or cross a gate at a required speed — challenges are guaranteed solvable. | Friction, normal force, static equilibrium tan α ≤ μ, stopping distance, piecewise MRUA |

| [Hanging sign](src/mechanics/statics-sign/index.html) (Enseigne suspendue) | Statics of a rigid bar (m₂, length L) on a frictionless wall pivot, held by a cable at angle θ with the wall, carrying a uniform sign (m₁) on two hooks (each m₁·g/2). Σ F⃗ = 0 and Σ M = 0 about the pivot give the cable tension T = [m₂gL/2 + (m₁g/2)(x_g + x_d)]/(L·cos θ) and the pivot reaction (R_x = T·sin θ, R_y = (m₁+m₂)g − T·cos θ); adjustable m₁, m₂, L, θ, sign position and hook spacing; angle-profile graphs T(θ) and \|R\|(θ). Static exercise (no transport panel). Experimental game mode "Accroche l'enseigne !": m₁ and θ imposed with cable and pivot ratings — choose where to hang the sign so neither breaks (sliding toward the pivot unloads the cable but loads the pivot); wrong placements drop the sign with a little animation. | Torques, static equilibrium Σ M = 0, cable tension, pivot reaction |

| [Blocks in contact](src/mechanics/blocks-in-contact/index.html) (Blocs en contact) | Two blocks A and B in contact pushed on a frictionless horizontal surface by a force F on the rear block (mA = 2 kg, mB = 3 kg, F = 20 N by default), g fixed at 9.81 m/s² for the vertical equilibrium N = m·g. The formula panel answers the course's four questions live: a = F/(mA+mB) = 4 m/s², contact force m_front·a = 8 N (Newton's third-law pair, drawn at the interface), net force on the pushed block m_rear·a = 12 N, and 12 N with the blocks swapped (a swap toggle re-orders the blocks in the scene). Adjustable mA, mB, F; free-body diagram isolating each block; MRUA graphs of x, v, a over a 15 m track. Experimental game mode "Protège l'œuf !": a massless egg is wedged between the blocks — masses imposed, pick F and the block order to cross the finish line within the time limit without exceeding the egg's contact-force limit (often only the light-block-in-front order works); challenges always solvable. | Newton's second and third laws, contact force, system vs isolated block, MRUA |
| [Two-radius pulley](src/mechanics/double-pulley/index.html) (Poulie à deux rayons) | Two cylinders fixed to one shaft (moment of inertia I, radii R₁ and R₂) on a frictionless axle; block m₁ hangs below a smooth nail from a massless rope wound on R₁ (the nail leaves T₁ unchanged), block m₂ hangs from R₂; released at rest with block 2 a gap h above block 1. Newton per block plus I·α = T₂·R₂ − T₁·R₁ and the constraints a₁ = α·R₁, a₂ = α·R₂ give α = g·(m₂R₂ − m₁R₁)/(I + m₁R₁² + m₂R₂²), the tensions T₁ = m₁(g + a₁), T₂ = m₂(g − a₂), and the blocks are level at t = √(2h/(a₁+a₂)) (marked live on the scene). Adjustable m₁, m₂, R₁, R₂, I, h, g; equilibrium (m₁R₁ = m₂R₂) and reversed motion handled; rotating-spoke pulley, weight/tension/velocity/acceleration vectors, free-body diagram of both blocks, graphs of heights, velocities and accelerations. Experimental game mode "La photo parfaite": geometry, h and m₂ imposed — tune m₁ and I so both blocks are level (±0.2 m) exactly when the camera flashes at an imposed instant; challenges generated around a reference grid solution, always solvable. | Rigid-body rotation I·α = Σ M, rope constraints a = α·R, tensions, MRUA, meeting time |

| [Block on a pushed wedge](src/mechanics/block-on-wedge/index.html) (Bloc sur un coin poussé) | A block (m = 0.5 kg) rests on the incline (α = 40°) of a wedge (M = 2 kg) pushed by a horizontal force F on a frictionless floor, with static friction µs = 0.6 between block and incline (kinetic µ = µs when sliding). While |f| ≤ µs·N the pair shares a = F/(m+M) with N = m(g cos α + a sin α) and f = m(g sin α − a cos α); the friction cone (φ = atan µs) bounds the no-slip window to F_min = (m+M)·g·tan(α−φ) ≈ 3.90 N and F_max = (m+M)·g·tan(α+φ) ≈ 71.08 N — the course answer, with the degenerate cases handled (F_min clamps to 0 when α ≤ φ, F_max = ∞ when α+φ ≥ 90°). Outside the window the exact constant-acceleration two-body solution makes the block visibly slide up or down the incline. Adjustable F, m, M, α, µs, g; angle arc, F/P/N/f vectors, free-body diagram, graphs of both bodies' positions/velocities/accelerations. Experimental game mode "Déménagement express": deliver the fragile crate across a finish line within a time limit without it sliding — fast enough yet inside the friction cone; always solvable. | Two-body system, accelerated frame, static friction cone, no-slip window, relative sliding |
| [Mass on a spring](src/mechanics/mass-spring/index.html) (Masse et ressort — trampoline) | A gymnast (m = 68 kg by default) falls from h = 3 m onto an ideal vertical spring trampoline (massless, linear, no losses, mass not attached); energy conservation m·g·(h+d) = ½·k·d² answers the course question k = 2·m·g·(h+d)/d² ≈ 2.27×10⁴ N/m for d = 45 cm. The k and d sliders are LINKED (editing d gives the course answer, editing k predicts d). Exact piecewise motion over two cycles: MRUA free fall, harmonic contact x(t′) = x_eq(1−cos ωt′) + (v/ω)·sin ωt′ about x_eq = m·g/k, symmetric ascent; markers for h, the lowest point d and x_eq; weight/spring-force vectors, free-body diagram, and graphs of y, v, a plus the three energies (E_c, E_p, E_el, E_tot constant). Experimental game mode "Défi trampoline": m, h and the frame depth D are imposed — pick k so the bed clears the frame (k ≥ 2mg(h+D)/D²) without exceeding the acceleration limit n·g at the lowest point (k ≤ mg(n²−1)/(2h)); always solvable. | Hooke's law, energy conservation, harmonic oscillation, piecewise MRUA, peak acceleration |

| [Spring, pulley and incline](src/mechanics/spring-pulley/index.html) (Ressort, poulie et plan incliné) | Block m₁ = 1 kg on a θ = 25° incline, tied to a spring (k = 16 N/m, natural length at start) anchored down the slope and, through a massless rope and ideal pulley, to a hanging block m₂ = 3 kg; kinetic friction µc = 0.11 (static taken equal). The energy theorem answers the course question: ½(m₁+m₂)v² = m₂gd − m₁g sinθ·d − ½kd² − µc·m₁g cosθ·d gives v ≈ 1.51 m/s after d = 20 cm (live card with the drop d as a parameter, marker on the scene). The exact full motion is a Coulomb-damped harmonic oscillation: half-periods π/ω about shifted centers (F ∓ f)/k, amplitude −2f/k per half-cycle, final sticking where \|F − k·x\| ≤ f (marker + card); adjustable m₁, m₂, k, θ, µc, d, g; all five forces on m₁ (P, N, T, spring, friction), P/T on m₂, free-body diagram, x/v/a graphs showing the linear Coulomb decay. Experimental game mode "Frein de descente": the setup is imposed and only µ is yours — the load must make its FIRST turnaround inside a golden zone, x_max = 2(F−f)/k being exactly the energy theorem with v = 0; always solvable. | Energy theorem with several works, spring energy, kinetic friction, constrained two-body motion, Coulomb-damped oscillation |

Adjustable E₁, E₂ (toggleable), q, initial height y₀ and horizontal speed u₀. | [Electric field](src/electromagnetism/electric-field/index.html) (Champ électrique) | Free-placement field map of the formulary's three canonical sources — point charge (E = k·q/r²), infinite charged line (E = λ/(2πε₀·r)) and infinite charged plate (E = σ/(2ε₀)) — drop them anywhere, drag them around, edit q/λ/σ and orientations; the superposed field is drawn as a log-scaled arrow grid and a draggable golden probe reads E⃗ (components and magnitude); a profile graph plots the field versus distance, showing the 1/r², 1/r and constant laws side by side. | [Gravity–Coulomb equilibrium](src/electromagnetism/gravity-coulomb/index.html) (Équilibre gravitation–Coulomb) | Two identical bodies (mass m, charge of absolute value q each) alone in deep space, released at rest at separation d₀ — no other force, spheres of radius 0.5 m treated as point masses/charges (contact at d = 1 m). Both forces scale as 1/d², so equilibrium requires k·q² = G·m² at every distance: q = m·√(G/k) ≈ 86.2 nC per tonne (≈ 5.4×10¹¹ protons or electrons), and the charges must have the same sign so the Coulomb repulsion opposes gravity. Off equilibrium the exact radial Kepler solution drives the motion (cycloid collapse / hyperbolic escape); adjustable m, \|q\|, sign toggle, d₀, with force vectors, free-body diagram, a heavily sped-up animation (factor displayed, physical time shown) and d, ḋ, d̈ graphs with auto-scaled unit prefixes. Experimental game mode "Amarrage spatial": m and d₀ imposed — tune \|q\| just below q_éq so the two craft touch below a random speed limit before the mission window expires; too little charge crashes them, too much and they drift apart. | Newton's gravitation, Coulomb's law, equilibrium of forces, elementary charge, radial two-body motion |
| [Electrostatic pendulum](src/electromagnetism/charged-pendulum/index.html) (Pendule électrostatique) | A charged sphere (m = 1.5 g, q = 8.9 nC by default) on a massless thread between two vertical infinite insulating plates of densities +σ and −σ a distance L = 5 cm apart: the uniform field E = σ/ε₀ deflects the thread to tan φ = q·E/(m·g), so E = m·g·tan φ/q ≈ 9.55×10⁵ V/m and ΔV = E·L ≈ 47.7 kV for φ = 30° (the course's two questions), with T = m·g/cos φ and σ = ε₀·E as bonus cards. The φ and ΔV sliders are linked (editing either recomputes the other); adjustable m, q, L, g; polarity signs and field arrows follow sign(ΔV); angle arc, force vectors and free-body diagram closing to ΣF = 0. Static exercise (no transport panel); profile graphs of ΔV(φ), E(φ) and T(φ). Experimental game mode "La charge mystère": q is hidden — vary ΔV, read φ, deduce q = m·g·L·tan φ/ΔV and validate the measurement within ±5 % (deflections guaranteed to reach 20° within the ΔV range). | Uniform field of charged plates, potential difference ΔV = E·L, static equilibrium of forces, measurement method |
| [Electron current](src/electromagnetism/electron-orbit/index.html) (Courant de l'électron — Bohr) | Classical Bohr picture of hydrogen: the electron (charge −e) circles the proton at R = 53 pm with v = 2200 km/s, held by the Coulomb attraction alone. The same charge e crosses any section once per period T = 2πR/v ≈ 151 as, so the average current is I = e/T = e·v/(2πR) ≈ 1.06 mA — the course answer, made tangible by a counting gate on the orbit (flash + turn/charge counter) and a Q(t) staircase graph against the average line I·t. The conventional current arrow runs opposite the electron; adjustable R (pm) and v (km/s); cards for T, f, ω, a = v²/R, and the bonuses µ = I·πR² (≈ the Bohr magneton) and B = µ₀I/(2R) ≈ 12.5 T at the center; canvas grid in picometers, times in attoseconds, slowdown factor displayed. Experimental game mode "Le générateur atomique": produce an imposed current (±2 %) by tuning both R and v — the whole line v = 2πR·I/e works; always solvable. | Average current I = Q/T, uniform circular motion, current loop, magnetic moment, orders of magnitude |
| [Approaching a charged sphere](src/electromagnetism/sphere-approach/index.html) (Approche d'une sphère chargée) | A point ball (q = 1 µC, m = 6×10⁻⁵ kg) is launched head-on from very far at a fixed insulating sphere uniformly charged (Q = 8 µC, R = 12 cm) in deep space; outside the sphere Gauss makes it a point charge, U(r) = kQq/r. Energy conservation ½mv∞² = kQq/r_min gives the turning radius r_min = 2kQq/(m·v∞²) and the course answer v_min = √(2kQq/(m(R+d))) ≈ 112.3 m/s to stay d = 7 cm above the surface (live card with d as a parameter; limit and turning circles drawn on the scene, collision case handled when v is too high, blocked case when the energy cannot even reach the display start r₀ = 2 m). Exact radial motion (closed-form hyperbolic time law, symmetric return); adjustable Q, q, m, v∞, R, d; F/v/a vectors, free-body diagram, graphs of r, ṙ, a and the E_c/U/E_tot exchange; grid in cm, times in ms, slowdown factor displayed. Experimental game mode "Frôle le bouclier !": Q, q, m, R imposed — pick v∞ so the probe turns around inside a golden ring above the shield; too slow misses the scan, too fast hits the shield; always solvable. | Electric potential energy, energy conservation, turning point, Gauss point-charge equivalence, repulsive radial motion |
| [Coaxial cable](src/electromagnetism/coaxial-capacitor/index.html) (Câble coaxial) | Cross-section of a cylindrical capacitor (inner cylinder +λ at radius a, outer tube −λ at radius b, length L): Gauss's theorem gives E(r) = λ/(2πε₀r) between the conductors (zero elsewhere), V(r) = λ/(2πε₀)·ln(b/r) with V(b) = 0, the difference V(a)−V(b) = λ/(2πε₀)·ln(b/a), the boundary condition E(a⁺) = σ_a/ε₀, the energy density u = ε₀E²/2, the capacitance C = 2πε₀L/ln(b/a) (geometry only) and the stored energy U = ½CV². Adjustable λ, a, b, L and an "uncharged outer tube" toggle (shows ΔV is unchanged, question 4); draggable radial probe and E(r)/V(r)/u(r) profiles. Static exercise. Experimental game mode "Conçois le câble": tune a, b, L to hit a target capacitance (±5%) without exceeding the insulator's breakdown field at the inner conductor (otherwise ⚡). | Gauss's theorem, cylindrical field/potential, capacitance, energy density, dielectric breakdown |

## Getting Started

Open `index.html` directly in a browser — no server, no install. Pages use classic scripts (no ES modules), so everything works over `file://`.

```bash
# Optional: serve locally instead
npx serve .

# Run the test suite
node --test
```

**Requirements:** Node.js ≥ 20 (tests only; the site itself runs in any modern browser).

## Project Structure

```
src/
  assets/
    images/          # shared images
    graphs/          # shared graphs
    js/              # shared visual/rendering code (canvas helpers, vectors, grid)
  <theme>/
    <exercise>/
      index.html     # exercise page (layout + styles)
      main.js        # rendering, camera, controls, formula panel, FR/EN strings
      calcul.js      # pure physics — self-contained per exercise, never shared
      game.js        # optional, experimental game mode — isolated, trivially removable
test/
  <theme>/
    <exercise>/
      main.test.js   # unit tests for calcul.js
.github/workflows/
  ci.yml             # runs node --test on every push and pull request
```

Design rules:
- **Physics is never shared.** Each `calcul.js` is self-contained and auditable in isolation, even at the cost of duplication.
- **Visual code is shared.** Canvas drawing helpers live in `src/assets/js/` and are loaded by exercise pages.
- **Computations are explicit.** No physics-engine library; every formula is implemented and unit-tested.
- **Works from `file://`.** Browser JS uses classic `<script>` tags (no ES modules); each file exposes one namespaced global (e.g. `projectile_calcul`, `canvas_draw`), which Node tests read after a side-effect import.

## Testing

Unit tests use Node's built-in test runner (`node:test`, no dependency). Every exercise tests its `calcul.js` against analytically known values. CI runs the full suite on push and pull request.
